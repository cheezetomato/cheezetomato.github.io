# cheezetomzto.github.io

cheezetomato의 개인 사이트입니다. GitHub Pages로 운영합니다.

사이트 주소: https://cheezetomato.github.io/cheezetomzto.github.io/

## 페이지

| 페이지 | 파일 | 내용 |
|---|---|---|
| Films (첫 화면) | [`index.html`](index.html) | 본 영화의 별점과 한줄평, 다시 본 기록, 통계 |
| Games | [`games/`](games/index.html) | 게임 목록 |
| 사과 게임 | [`games/apple.html`](games/apple.html) | 합이 10이 되게 묶는 퍼즐 |
| 십이장기 | [`games/janggi.html`](games/janggi.html) | 3×4 판 미니 장기, AI·온라인 대전 |
| 지뢰찾기 | [`games/minesweeper.html`](games/minesweeper.html) | 추측 없이 풀 수 있는 지뢰찾기 |

예전 주소 `movie.html`은 첫 화면으로 넘어갑니다.

## 폴더

- `games/`: 게임 페이지
- `assets/`: 링크 미리보기 이미지 등 공용 파일
- `.github/`: 영화 기록 자동 백업 (매주 월요일, `backup` 브랜치에 저장)
